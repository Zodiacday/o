# PreviewPort mobile client

PreviewPort is a borderless mobile player for Flutter web development
previews. Its companion CLI starts the project on the developer's computer and
prints a QR code. Scanning that code inside the app opens the project in an
immersive full-screen WebView without browser tabs, address bars, or navigation
chrome.

## Supported connections

- Versioned `previewport://connect` QR payloads generated by PreviewPort CLI
- Legacy `fluttergo://connect` QR payloads for backward compatibility
- Plain HTTP and HTTPS QR codes
- HTTP and HTTPS URLs pasted from the clipboard or entered manually

Local HTTP access is intentionally enabled for development servers. The phone
and computer must be on the same network unless the supplied URL is reachable
through a tunnel.
